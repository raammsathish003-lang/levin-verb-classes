# Levin-style verb classes (VerbNet 3.4)

A searchable, offline-friendly page of English verb classes from [VerbNet 3.4](https://verbs.colorado.edu/verbnet/), the University of Colorado lexicon that extends Beth Levin’s 1993 classification with further classes and subclasses.

Open [index.html](index.html) in a browser, or the GitHub Pages site:
**https://raammsathish003-lang.github.io/levin-verb-classes/**

This site uses only the freely licensed VerbNet lexicon, not the Levin book itself.

## Data

- VerbNet 3.4 from [cu-clear/verbnet](https://github.com/cu-clear/verbnet) (`verbnet3.4`, commit `ae8e9cfd`)
- 329 classes, 280 subclasses, 4,580 unique verbs, 1,602 frames
